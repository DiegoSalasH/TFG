# SuiteCRM: paquete «Gestión de Extraescolares»

Aquí irá el paquete de extensión para SuiteCRM 8 (tareas T7–T10 del plan). Solo debe contener configuración y extensiones, nunca datos reales.

Contenido previsto:

- Módulos: Alumnos, Personas autorizadas, Actividades, Grupos, Sesiones, Inscripciones, Asistencias, Eventos de custodia e Incidencias.
- Roles y grupos de seguridad (monitor, coordinación, administración, dirección).
- Workflows de escalado y comunicación de incidencias.
- Guía de instalación en un entorno local.

Estado: pendiente de instalar la instancia y ejecutar las pruebas de concepto PC01–PC07 (hito H2).
